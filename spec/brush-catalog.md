# Stock brush catalog (M2 goal)

Goal: functional coverage of the stock brushes of **Infinite Painter** (168 pcs., features/03-brushes/infinite-painter.md) and **ibisPaint** (a stock set of ≈142 types according to the store description, positions known from the lessons). Names, heads, textures and parameters are our own. Assets are generated by `tools/gen_assets.py`.

The "Engine" column = which brush-engine features are needed. All of this moves into M2.

## Engine features that move into M2
Watercolor sim, particles, scatter-particles, harmony, double type, color stamp (base hue-shift), 3D shading stamp, filter brushes (blur, glow), screentone snap, fill brushes, texture modes warp/rotate/moving, structure/depth, glaze, wet edges, adhesion, velocity/tilt/azimuth dynamics, size/flow profiles.
