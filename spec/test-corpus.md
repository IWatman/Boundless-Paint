# Тестовый корпус и приёмка

## JVM unit-тесты (`:core`)
- **Blend**: для каждого из 33 режимов таблица входов (Cb, Cs, αb, αs) → ожидаемый результат по формулам blend-and-color.md, допуск 1e-3.
- **Tiles**: запись и чтение, пустые тайлы, границы, копирование регионов, LZ4 round-trip.
- **Undo**: последовательности команд → состояние совпадает после undo/redo (хэш тайлов).
- **Stroke resampler**: шаг = spacing·size ±1%. Сглаживание не удлиняет прямую. Тапер на концах.
- **Stabilizer**: синус с шумом → RMS отклонения убывает с ростом smoothing.
- **Flood fill** (M2): эталонные маски на синтетических лайнартах (замкнутый круг, круг с разрывом 3 px, AA-линии).
- **Color**: HSB↔RGB↔LAB↔hex round-trip.
- **Формат .pnt**: save → load → идентичные хэши. Миграция schema.

## Эталонные картинки (golden, генерация `tools/gen_goldens.py` в .venv)
- Синтетические: градиенты, лайнарт-сетки, AA-круги, шахматки.
- Golden-рендер мазков (M2+): сервис рендера `:core` в CPU-режиме (референсная реализация штампа) → PNG. Сравнение PSNR ≥ 40 dB.

## Ручная приёмка на устройстве (чек-лист вехи)
- Задержка мазка (визуально, а с M3 через замер timestamp event → frame).
- Жесты: pan, zoom, rotate, undo 2 пальца, redo 3 пальца.
- Сохранение, перезапуск, восстановление.
