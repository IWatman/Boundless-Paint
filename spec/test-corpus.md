# Test corpus and acceptance

## JVM unit tests (`:core`)
- **Blend**: for each of the 33 modes a table of inputs (Cb, Cs, αb, αs) → the expected result by the formulas in blend-and-color.md, tolerance 1e-3.
- **Tiles**: write and read, empty tiles, bounds, copying regions, LZ4 round-trip.
- **Undo**: command sequences → the state matches after undo/redo (tile hash).
- **Stroke resampler**: step = spacing·size ±1%. Smoothing does not lengthen a straight line. Taper at the ends.
- **Stabilizer**: a sine with noise → the RMS deviation decreases as smoothing grows.
- **Flood fill** (M2): reference masks on synthetic line art (closed circle, circle with a 3 px gap, AA lines).
- **Color**: HSB↔RGB↔LAB↔hex round-trip.
- **.pnt format**: save → load → identical hashes. Schema migration.

## Reference images (golden, generated by `tools/gen_goldens.py` in .venv)
- Synthetic: gradients, line-art grids, AA circles, checkerboards.
- Golden render of strokes (M2+): the `:core` render service in CPU mode (reference dab implementation) → PNG. Comparison PSNR ≥ 40 dB.

## Manual acceptance on the device (milestone checklist)
- Stroke latency (visually, and from M3 via measuring timestamp event → frame).
- Gestures: pan, zoom, rotate, undo 2 fingers, redo 3 fingers.
- Saving, restart, recovery.
