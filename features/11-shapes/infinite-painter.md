# Infinite Painter: Shapes

Источник: User Guide /painter/shapes/*.

## Общее
- Shape = один геометрический мазок текущей кистью. Любая кисть, любой режим (Paint, Blend, Erase, Clone).
- Редактируем, пока не тапнули мимо, не начали новый шейп или не закрыли инструмент.
- 5 инструментов: Line, Rectangle, Circle, Path, Arc.
- Mini-toolbar:
  - иконка инструмента (закрыть);
  - **Stamp**: оставить копию и продолжить редактировать. У каждой копии может быть свой size, opacity, цвет, поворот.
- Filled shapes = шейп + Fill brush.
- Шейпы растровые: после фиксации это обычные пиксели.

## Line
- 2 конечные точки, правятся после рисования.
- Touch-Alt: шаг 15°.
- К перспективе не снапится (специально): так строят временные точки схода.

## Rectangle
- Ручки:
  - start / end corner;
  - move;
  - corners (resize);
  - vertical / horizontal stretch;
  - rotate.
- Touch-Alt: квадрат при рисовании, шаг поворота 15°.

## Circle
- Круг, при редактировании превращается в эллипс. Touch-Alt: ось с шагом 15°.

## Path
- Bézier/полилиния как в Pen guide: smooth = G1, cusp = G0. Close, Confirm (✓ = фиксация), Stamp.

## Arc
- Дуга окружности: start, middle (кривизна или радиус), end.

## Shape detection
- Держать стилус ~1 с в конце мазка → мазок превращается в чистую фигуру.
- Распознаются 8 фигур:
  - Line;
  - Arc;
  - Path smooth;
  - Path polyline;
  - Triangle;
  - Rectangle;
  - Quadrangle;
  - Ellipse/circle.
- Больше 4 углов → эллипс.
- Сразу после распознавания:
  - правится последний узел;
  - у эллипса и прямоугольника правятся размер и угол;
  - дальше тап по линии = обычное редактирование шейпа.
- Отключается в Settings.

## Shapes in perspective
- Rectangle и Circle в активной перспективной сетке (кроме плоской 2D) рисуются на одной из 3 плоскостей.
- Плоскость выбирается начальным направлением мазка (к точке схода или вдоль линий сетки). После рисования плоскость не меняется.
- Редактирование (move, resize, rotate) проецируется на плоскость.
- Curvilinear: только сокращение, без кривизны.
- Stamp работает.
