# ibisPaint: библиотека кистей и управление

Источник: ibispaint.com/lecture (№104, 137, 152, 155, 175, 200), app store listing.

- Библиотека: 15000+ кистей, большей частью онлайн-контент.
  - Категории: dip pen, felt tip, digital pen, airbrush, fan, flat, pencil, oil, charcoal, crayon, stamps.
  - Кисти-цепочки и кружево, кисти-штампы.
- Brush Window:
  - вкладки категорий + **Custom**;
  - **Search** по имени;
  - панель параметров (кнопка `>`).
- **Custom brush**:
  - «+» на базовой кисти → копия в Custom → правка → `<` сохраняет;
  - Edit: порядок (drag) и Delete;
  - Reset возвращает к состоянию при добавлении.
- **Export/Import через QR-код** (картинка в фотоальбом). Шаринг в соцсетях с #ibispaint.
- **Публикация в Online Gallery**: QR вставляется в артворк, артворк загружается, кисть появляется в галерее с задержкой.
- Онлайн-библиотека: загрузка паттернов по требованию. Settings → «Delete the Brush Pattern images» (кэш).
- **Original brush patterns** (свой паттерн): см. 04 ibispaint.md.

Для clean-room: QR-обмен кистями — хорошая идея для кросс-девайс шаринга. Делаем свой формат + опциональный QR-экспорт.
