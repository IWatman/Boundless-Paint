# Infinite Painter: слои

Источник: User Guide /painter/layers/*.

## Модель
- Обычный слой: RGBA, размер холста. Лимит числа слоёв = память. Показывается в диалоге размера холста.
- Активен один слой. Исключение: Transform, там можно мультивыбор.
- Специальные слои (не битмап):
  - Adjustment;
  - Filter;
  - Panels (комикс-рамки);
  - Text.
- **Paper**: нижний фон, не рисуется, не перемещается.
- Мультиселекта слоёв в панели нет.

## Layer panel
- Тоггл в top bar.
- Collapsed (дефолт): слайд влево = развернуть, вправо = свернуть.
  - кнопка Add;
  - мини-глаз;
  - тап = активировать, повторный тап = options;
  - long-press + drag = порядок (временно разворачивает);
  - **pinch по слоям = сгруппировать**;
  - иконка Paper.
- Expanded:
  - Add layer (над активным);
  - Add special layer;
  - New group (из активного);
  - индикатор Visibility mode (→ Rendering panel);
  - тайлы.
- Тайл:
  - превью с бейджами blend mode (если не Normal) и opacity (если <100%);
  - имя;
  - глаз.
  - Активный: красная рамка. Неактивный: серая.

## Layer options
- Rename: любые символы, эмодзи, не уникально.
- Blending mode (дефолт Normal).
- Opacity 0–100%. При 0 слой не редактируется.
- Hide: скрытый слой не редактируется.
- Duplicate: копия над оригиналом, имя то же.
- Clear: отменяемо.
- Lock transparency (alpha lock).
- Merge (вниз):
  - результат берёт имя и blend нижнего, opacity 100%;
  - merge с adjustment-слоем запекает коррекцию и убирает её с остальных;
  - merge с группой ниже схлопывает группу.
- Delete: по умолчанию НЕ отменяемо.
- Clip (к слою ниже).
- Select: выделение по альфе слоя.
- Mask.
- More… → **Hide when recording** (исключить из таймлапса).

## Группы
- Создание:
  - pinch по подряд идущим слоям;
  - кнопка Group (группа из активного) + перетаскивание остальных.
- Вложенность без лимита. Больше 5 уровней непрактично.
- Collapsed / expanded. Красная иконка папки = активный слой внутри.
- Опции группы:
  - Rename;
  - Blending (дефолт **Passthrough**);
  - Opacity;
  - Hide;
  - Duplicate;
  - **Copy Merged** (новый слой = композит, группа цела);
  - **Flatten**;
  - Merge (вниз);
  - Delete;
  - Clip;
  - Select (по суммарной альфе);
  - Ungroup;
  - Mask;
  - Hide when recording.
- **Passthrough vs Normal**:
  - Passthrough: adjustment-слои внутри группы действуют на всё ниже группы;
  - Normal (и другие режимы): группа изолирована, коррекции действуют только внутри неё.

## Маски слоя
- 8-bit grayscale, одна на слой. Белый = видно, чёрный = скрыто. Новая маска белая.
- Если есть активное выделение, маска создаётся из него.
- Поддержка: обычные, adjustment, filter слои и группы.
- Редактирование: все кисти и режимы, фильтры, коррекции. Саму маску не видно, видно только результат. Активная маска обведена красной рамкой.
- Опции маски:
  - имя фиксировано;
  - Strength (как opacity маски);
  - Fill (чёрным);
  - Invert;
  - Clear (белым);
  - Hide;
  - **Apply** (запечь и удалить маску);
  - Delete;
  - **Linked** (дефолт on: трансформируется вместе со слоем);
  - Select (выделение из маски).

## Clipping
- Слой обрезается альфой слоя ниже (как в PS). Тоггл Clip, индикатор = стрелка вниз.
- Несколько слоёв на одну базу, можно клипать группу.
- Adjustment/filter в клипе действует только на базовый слой.
- Adjustment-слой не может быть базой (в нём нет пикселей). Panels и Text могут.

## Special layers
- **Adjustment layers**: 11 типов (см. 17-adjustments).
  - Имя = тип, переименовать нельзя.
  - **Strength** (дефолт 0 = нет эффекта) отдельно от opacity.
  - Merge = применить к слою ниже. Merge двух adjustment = пустой слой.
  - Select transparency неактивен.
- **Filter layers**: 27 фильтров доступны как неразрушающие слои, контролы те же.
- **Panels layer**, **Text layer**: редактируемые, Rasterize необратимо.
- Все спецслои: порядок, группировка, дубль, удаление, blend, opacity, маска.

## Paper layer
- Опции:
  - Paper color (палитра оттенков бумаги);
  - Texture on/off;
  - выбор текстуры (+ импорт);
  - **Texture depth** (влияние на мазки всех слоёв);
  - **Texture opacity** (визуальная сила);
  - **Texture scale**.
- Используется только grayscale-канал текстуры.
- Hidden Paper = шахматка, прозрачный экспорт. Текстура при этом остаётся видна.
- PSD может не сохранить точный вид Paper.

## Rendering panel (тап по visibility mode)
- Color proofing + gamma correction (см. 05-color).
- Visibility modes:
  - **Normal**: всё видно;
  - **Solo**: только активный. Совет: скетчбук «по страницам», листать слои кнопками громкости;
  - **Trace**: активный полностью видно, нижние **прогрессивно** тускнеют. Opacity слоёв не меняется. На выходе предлагается скрыть «trace»-слои.
