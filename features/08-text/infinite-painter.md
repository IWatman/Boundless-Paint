# Infinite Painter: текст (v7.2+)

Источник: User Guide /painter/text/*.

## Назначение и модель
- Короткий текст: заголовки, подписи, баллоны. Не вёрстка.
- Каждый текстовый объект хранится отдельным **Text layer**, остаётся редактируемым.
- Поддержка LTR/RTL и не-латиницы. Нет глифа в шрифте → берётся ближайший системный шрифт.
- Форматирование на весь слой. Форматирования фрагментов нет.
- Нет: отступов абзацев, буквиц, переносов (7.2).

## Создание
- Creative Tools → Text. Слой создаётся над активным обычным слоем.
- Нельзя добавить, если активен спецслой (adjustment, filter, panels, text). Tools-меню в этом случае недоступны.
- Дефолтный текст «Double Tap to Edit».
- Редактор: двойной тап или кнопка клавиатуры. Ввод любым IME, вставка из буфера. OK.
- Confirm: закрыть workspace, вернуть последний рабочий слой. Cancel: отменить всё за сессию.
- Повторное редактирование: активировать text layer.

## Text frame
- Рамка всегда вмещает весь текст.
- Угловые ручки: масштаб текста. Боковые: ширина рамки (перенос строк), высота подстраивается автоматически.
- Перетаскивание. Направляющие при движении и ресайзе:
  - зелёные: центры блока;
  - красные: края текста;
  - серые: строки;
  - синие: оси холста со snap.

## Toolbar
- Keyboard.
- **Size**: слайдер возвращается в центр (относительный «джог»), значение в px.
- **Fonts**:
  - семейства → варианты (веса);
  - variable fonts: слайдер на каждую ось;
  - «flexible fonts»: доп. настройки.
- **Color** (fill). В режиме Outline only это цвет контура.
- **Outline**:
  - Outline only / Outline + fill;
  - толщина px (0 = выкл);
  - цвет.
- **Format**:
  - Align left / center / right;
  - Case: Normal, ALL CAPS, lowercase, Small caps (если шрифт поддерживает).
- **Spacing**:
  - Letter (0 = дефолт шрифта, ±);
  - Word;
  - Line (% от размера, обычно 100–120, <100 = наложение строк).
- **Justify**:
  - Traditional (через letter и word spacing, нужно >25 символов в строке);
  - **Scale-justification** (подгонка высоты, то есть размера, каждой строки под ширину);
  - **Balance lines** (выравнивание длин строк без изменения spacing).
- **To Image**: растеризация, необратимо.

## Шрифты
- 18 встроенных семейств Google Fonts (OFL/Apache), >100 начертаний. Вариативные: Fraunces, Fredoka, Roboto Flex.
- Латиница, у части кириллица и греческий. Арабского, иврита, CJK нет, нужны свои шрифты.
- Импорт TTF/OTF через «+» (системный файловый менеджер, облако). Установка прямо из Google Fonts не поддерживается.
- Удаление custom: long-press → Delete. Встроенные не удаляются.
- Отсутствующий шрифт:
  - предупреждение при открытии;
  - рендер системным шрифтом;
  - после переустановки вид восстанавливается автоматически;
  - имя шрифта можно скопировать.

## Приёмы (не встроены)
- Тень = растеризованная копия. Сложная обводка = дубли слоя, clipping.
