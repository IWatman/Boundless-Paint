# ibisPaint: text

Source: ibispaint.com/lecture №37, 185.

- Text tool → Add Text → input → ✓. Several text objects, each with its own settings.
- **Vertical / horizontal** writing (important for manga).
- Align: Left / Center / Right.
- Font: system fonts + web fonts. Uninstall fonts in Settings.
- Tabs:
  - **Size**;
  - **Style**: text color;
  - **Stroke**: color and thickness of the outline;
  - **Background**: color + opacity (default 0) of a rectangular plate, **margin W/H**;
  - **Spacing**: letter and line spacing.
- The text list: swipe left → **Order** (z-order) / **Delete**.
- Tapping a text = edit it.
- Claimed: Vertical, Horizontal, Stroke, Font select, Multiple text.

## What to add to IP
- Vertical text (CJK, glyph-rotation rules).
- A background plate with margins.
- A text list with z-order (in IP each text = a layer, and that is the order).
- IP is richer: variable fonts, justify, case, outline-only, RTL.
