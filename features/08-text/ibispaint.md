# ibisPaint: текст

Источник: ibispaint.com/lecture №37, 185.

- Text tool → Add Text → ввод → ✓. Несколько текстовых объектов, у каждого свои настройки.
- **Вертикальное / горизонтальное** письмо (важно для манги).
- Align: Left / Center / Right.
- Font: системные + веб-шрифты. Uninstall fonts в Settings.
- Вкладки:
  - **Size**;
  - **Style**: text color;
  - **Stroke**: цвет и толщина обводки;
  - **Background**: цвет + opacity (дефолт 0) прямоугольной плашки, **margin W/H**;
  - **Spacing**: межсимвольный и межстрочный.
- Список текстов: свайп влево → **Order** (z-порядок) / **Delete**.
- Тап по тексту = редактирование.
- Заявлено: Vertical, Horizontal, Stroke, Font select, Multiple text.

## Что добавить к IP
- Вертикальный текст (CJK, правила поворота знаков).
- Фоновая плашка с отступами.
- Список текстов с z-order (у IP каждый текст = слой, это и есть порядок).
- IP богаче: variable fonts, justify, case, outline-only, RTL.
