# ibisPaint: Canvas tool

Источник: ibispaint.com/lecture №39, 40, 41, 77, 178.

- **Change Canvas Size**: W/H px, Keep Aspect Ratio, **Origin** (якорь).
- **Trim**: ручки области, ✓.
- **Resize**:
  - режим px (для экрана) / **Print** (mm + dpi);
  - Keep Aspect;
  - Interpolation: Bilinear / Color Average / Nearest Neighbor.
- **Color Mode**: Color / Grayscale / B&W.
- Flip canvas H/V (Layer window).
- dpi задаётся при создании и в Resize.

## Что добавить к IP
