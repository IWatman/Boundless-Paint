# Infinite Painter: инструменты холста

Источник: User Guide /painter/canvas/*. Действуют на весь проект, а не на слой (Editing Tools → Canvas).

## Crop (неразрушающий)
- Прячет области, не удаляет. Скрытое не редактируется, но восстанавливается.
- Toolbar:
  - Cancel;
  - W, H;
  - lock proportions;
  - swap;
  - Confirm.
- Сетка 3×3 ручек: углы = пропорционально, стороны = при lock.

## Resize
- Toggle **Resize content**:
  - off: обрезка или расширение холста. Удалённое стирается, но virtual transformation держит обратимость до правки пикселей;
  - on: ресемплинг всех слоёв.
- Toolbar:
  - W/H в px;
  - lock ratio;
  - старый и новый размер.
- Метод ресемплинга и якорь не описаны. Якорь задаётся сеткой из 9 ручек.

## Straighten
- Rotate (drag), Vertical perspective, Horizontal perspective. Можно совмещать.
- Reset geometry. Undo работает.
- Пиксельные размеры холста сохраняются. Вылетевшее за край теряется.
- Совет: чтобы не терять, сначала Resize, потом Distort всех слоёв.

## Panels (комикс-рамки) → спецслой Panels
- Outer frame W/H, **gutter width**, **gutter color**.
- Divider:
  - начинается и заканчивается на рамке или другом divider;
  - может быть не перпендикулярным;
  - тап = ручки;
  - drag конца с линии = удалить.
- Нужен минимум 1 divider (чтобы получить только рамку: создать divider и удалить).
- Редактирование существующего слоя в реальном времени, без Cancel/Confirm.
- **Мазок, начатый внутри панели, ограничен этой панелью.**
- Слой: opacity, blend, mask, select, может быть clipping-базой. Несколько Panels-слоёв.
- Растеризация: merge с пустым слоем.
