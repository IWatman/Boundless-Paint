# ibisPaint: symmetry

Source: ibispaint.com/lecture №47, 48. Implemented through the Ruler tool.

- **Mirror Ruler**: Phase (axis angle), position. A mirror.
- **Kaleidoscope Ruler**: Division (number of sectors), Phase (angle). Lace.
- **Radial Ruler**: not symmetry but rays (see 10).
- **Array Ruler**: translational "symmetry" in a grid up to 10×10 with perspective (see 10).

## Mapping to IP
- IP Symmetry covers Mirror/Kaleidoscope and gives more: Radial rotation, Fan angle, Crop on axis, 2–16 planes.
- New from ibis: Array (translational) symmetry → add it as a 5th Symmetry type "Array/Grid" with a perspective frame.
