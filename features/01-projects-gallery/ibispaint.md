# ibisPaint: canvas and gallery (My Gallery)

Source: ibispaint.com/lecture №3, 20, 41, 103, 157, 170, 182, 188, 193.

## Creating a canvas
- Create New Canvas:
  - presets (A4/B4 with dpi, screen-sized);
  - **Animation** (fps);
  - **Manga Manuscript** (Fanzine / Manga / American Comic);
  - Custom W×H mm + dpi;
  - Specify by Print Size;
  - Brush Pattern (pattern editor).
- **Max 16384×16384 px**, in practice limited by the device. Performance warning.
- The layer limit depends on the canvas size (a smaller resize = more layers).

## My Gallery
- List of artworks, Enlarged View (flick between works, **drawing time**).
- Buttons: Edit, Playback (timelapse), Share, Duplicate, Artwork Information (title, upload, URL).
- **Artworks Folder**:
  - + → Folder, or drag one artwork onto another = folder;
  - nested folders;
  - long-press drag into a folder, Back = out of it;
  - multi-select (Select → Folder icon → Move / New Folder);
  - rename;
  - the structure is synchronized to the cloud.
- **Downloads Folder**: things downloaded from the Online Gallery.
- **Rearrange artworks**.
- **Temporary storage for deleted artworks** (trash).
- **Save Artwork at This Point**: while playing back a timelapse, save a past state as a new IPV. This is the analogue of IP's version history, only derived from the recording.

## What to add to IP
- Drawing time on the card.
- Trash for deleted items.
- Multi-select in the gallery.
- Restoring a state from a timelapse (IP has version history: merge = "History from the timelapse + snapshots").
- Animation and Manuscript canvas types in the New Project creator.
