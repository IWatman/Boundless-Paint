# ibisPaint: холст и галерея (My Gallery)

Источник: ibispaint.com/lecture №3, 20, 41, 103, 157, 170, 182, 188, 193.

## Создание холста
- Create New Canvas:
  - пресеты (A4/B4 с dpi, экранные);
  - **Animation** (fps);
  - **Manga Manuscript** (Fanzine / Manga / American Comic);
  - Custom W×H mm + dpi;
  - Specify by Print Size;
  - Brush Pattern (редактор паттерна).
- **Max 16384×16384 px**, реально ограничено устройством. Предупреждение о производительности.
- Лимит слоёв зависит от размера холста (ресайз меньше = больше слоёв).

## My Gallery
- Список артворков, Enlarged View (флик между работами, **время рисования**).
- Кнопки: Edit, Playback (таймлапс), Share, Duplicate, Artwork Information (title, upload, URL).
- **Artworks Folder**:
  - + → Folder или drag работы на работу = папка;
  - вложенные папки;
  - long-press drag в папку, на Back = наружу;
  - мультивыбор (Select → Folder icon → Move / New Folder);
  - rename;
  - структура синхронизируется в облако.
- **Downloads Folder**: скачанное из Online Gallery.
- **Rearrange artworks**.
- **Temporary storage for deleted artworks** (корзина).
- **Save Artwork at This Point**: при проигрывании таймлапса сохранить прошлое состояние как новый IPV. Это аналог истории версий IP, только из записи.

## Что добавить к IP
