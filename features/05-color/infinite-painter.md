# Infinite Painter: цвет

Источник: User Guide /painter/color/*.

## Цветовой конвейер (важно для движка)
- Внутренняя глубина **64 bpp**: 16 бит на RGB-канал + 16 бит альфа. Цель: гладкие градиенты и мазки, безопасное редактирование.
- Гамут sRGB. CMYK-изображения не поддерживаются, CMYK-слайдеры только переводятся в RGB. K не углубляет чёрный: чёрный = RGB 0,0,0.
- **Gamma correction** (тоггл в Layers panel или Settings):
  - смешение полупрозрачного «как свет», меньше лишнего контраста на перекрытиях;
  - влияет на мягкие края, смешение слоёв, полупрозрачные градиенты, фильтры;
  - может давать бандинг;
  - смена режима меняет вид старых проектов.
- **On-screen proofing** (меняется только отображение, не пиксели), Color mode:
  - sRGB (дефолт);
  - CMYK-профили (Generic CMYK и др.);
  - Grayscale;
  - Line Art (все слои в Line Art blending);
  - симуляция дальтонизма.
  - С 7.1 настройка глобальная в Settings.

## Color panel (клавиша C)
- 4 инструмента-вкладки:
  - HSB wheel;
  - Sliders;
  - Main swatch palette;
  - Lighting Orb.
- Помнит последнюю вкладку.
- Один текущий цвет. Отдельного фонового цвета нет. Всё синхронно.
- Цвет в Fill и Paper не меняет основной цвет.
- Тот же селектор используется в Fill, Paper, Text color и некоторых фильтрах.
- Элементы:
  - шестерёнка Settings;
  - предыдущий и текущий цвет;
  - пипетка;
  - компактная палитра;
  - навигация по вкладкам.
- **Floating swatch**: вытащить текущий цвет на холст для сравнения. Живёт, пока открыт panel.
- **Compare tone**: показывает серый тон (HSB brightness) цвета под свотчем относительно текущего и предыдущего. Позволяет менять H/S при постоянном тоне.

## Пипетка
- Вызов:
  - иконка;
  - вытягивание от цветового индикатора тулбара или Solid Fill;
  - жест пальцем;
  - кнопка стилуса;
  - клавиша I;
  - long-press по холсту (дефолт).
- Drag → отпустить = подтвердить. Кольцо показывает точку сэмпла.
- Сэмплит холст и референсы.
- Sample area: 1–100 px (усреднение по радиусу).
- Sample all layers (дефолт ON):
  - ON: все слои + Paper (скрытая Paper = белый);
  - OFF: только текущий слой. Корректирующие слои выше игнорируются.

## История цветов
- До 10 цветов. Recent strip на тулбаре + секция вверху Main palette.
- Drag по strip листает с большим превью.
- Почти одинаковые цвета усредняются, а не добавляются.
- Strip скрываемый.

## Color wheel (HSB)
- Hue-кольцо (S=B=100%), S-B поле, маркер комплементарного цвета (считается в RGB, а не HSB).
- Внешнее кольцо указателя = предыдущий цвет.
- **Tone Lock** (тап по hue-указателю, дефолт OFF): при смене hue автоматически корректируются S/B для равной воспринимаемой яркости.
- 6 стилей (глобально):
  - Square (большое S-B поле + линейный hue);
  - Round (S-B на круге);
  - Default (XY-поле внутри кольца);
  - Diamond (S-B повернут на 45°: легче чистые белый и чёрный);
  - Triangle (насыщенный справа, белый сверху, чёрный снизу);
  - Combo (S и B двумя дугами + большой свотч в центре).
- **Widget**: вытащить двумя пальцами на холст, pinch для масштаба, закрыть перетаскиванием на ✖.

## Sliders
- Модели:
  - HSB: H 0–360, S/B 0–100;
  - RGB: 0–255;
  - LAB: L 0–100, a/b −128…+127 (интерпретация: светлота, tint, temperature);
  - CMYK: 0–100.
- Полоса слайдера окрашена возможными цветами. Тап по краям = точный шаг. Тап по числу = ввод.
- **Hex**: ввод/копирование, с `#` и без, сокращение `#F00`.

## Swatch palettes
- **Collection**: набор открытых палитр в Main tab. Компактная палитра под wheel/sliders синхронна.
- Компактная палитра:
  - + добавить текущий цвет;
  - имя (выбор палитры);
  - горизонтальный скролл = смена палитры.
- Меню коллекции: New, Open, Save (как новую), Rename, Remove (только из коллекции).
- **Library**: пресеты (не удаляются) + custom (без лимита). Long-press: Rename, Share `.clrs`, Delete.
- Импорт:
  - `.clrs` (свой формат);
  - **Smart palette** из изображения (картинка не импортируется);
  - **Camera** (фото не сохраняется).
- С палитрами Photoshop и др. несовместимо.
- Редактирование:
  - + = добавить в конец;
  - long-press + drag = переставить;
  - вынести за палитру = удалить (без подтверждения).

## Lighting Orb
- Сфера, освещённая моделью «свет + базовый цвет + тень».
- Контролы:
  - пикер на сфере;
  - Light color;
  - Base color;
  - Shadow color;
  - Hue и Saturation выбранного из трёх;
  - Contrast (интенсивность света и тени).
- Яркость света и тени регулирует Contrast, а не Saturation.
- Идея использования: тёплый свет + холодная тень.
