# ibisPaint: цвет

Источник: ibispaint.com/lecture №11, 15, 178, 195, 207.

- Color window:
  - Current / Previous;
  - Color circle + HSB box;
  - Hex;
  - слайдеры H, S, B (или R, G, B);
  - **Opacity** цвета (у IP нет: в IP opacity задаётся у кисти);
  - Palette screen.
- **Color History** до **100** цветов (у IP 10).
- Палитра: drag текущего цвета в палитру = сохранить. **Multiple Color Palettes**. Reset palettes.
- Пипетка (Eyedropper tool):
  - Reference **Canvas** (как видно) / **Current Layer** (как хранится);
  - Quick Eyedropper (long-press, лупа, настраиваемая задержка);
  - ПКМ на десктопе;
  - пипетка в Reference window;
  - **Contents Layer Selection** (кнопка «перейти на слой пикселя»).
- Цветовой режим холста: Color / Grayscale / Black&White (реальный, не proofing) (см. 26).
- CMYK только на экспорте (профили, intent, BPC) (см. 23).
- Глубина цвета в доке не указана (предположительно 8 bpc).

## Что добавить к IP
- Opacity в цвете.
- История до 100.
- Contents Layer Selection.
- Grayscale/BW как режим документа.
