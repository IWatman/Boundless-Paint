# ibisPaint: color

Source: ibispaint.com/lecture №11, 15, 178, 195, 207.

- Color window:
  - Current / Previous;
  - Color circle + HSB box;
  - Hex;
  - H, S, B sliders (or R, G, B);
  - the **Opacity** of the color (IP does not have this: in IP opacity is set on the brush);
  - Palette screen.
- **Color History** up to **100** colors (IP has 10).
- Palette: drag the current color into the palette = save it. **Multiple Color Palettes**. Reset palettes.
- Eyedropper (the Eyedropper tool):
  - Reference **Canvas** (as visible) / **Current Layer** (as stored);
  - Quick Eyedropper (long-press, magnifier, configurable delay);
  - the right mouse button on desktop;
  - the eyedropper in the Reference window;
  - **Contents Layer Selection** (the "jump to the pixel's layer" button).
- Canvas color mode: Color / Grayscale / Black&White (real, not proofing) (see 26).
- CMYK only on export (profiles, intent, BPC) (see 23).
- The color depth is not stated in the doc (presumably 8 bpc).

## What to add to IP
- Opacity in the color.
- History up to 100.
- Contents Layer Selection.
- Grayscale/BW as a document mode.
