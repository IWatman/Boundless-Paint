# Infinite Painter: цветокоррекция

Источник: User Guide /painter/adjustments/*.

## Инструменты (Editing Tools → Adjustments)
- Деструктивно, только активный слой или выделенный фрагмент.
- Неразрушающе: Adjustment layers (11 типов: эти 9 + Curves + ещё 1, точный список уточнить по приложению).

| Группа | Коррекция | Поведение |
|---|---|---|
| Light | Brightness | −100…+100%. −100: яркость −50% (белый → 50% серый), +100: чёрный → 50% серый |
| Light | Contrast | — |
| Light | Exposure | «естественная» светлота, чёрный остаётся чёрным |
| Light | Gamma | средние тона |
| Color | Saturation | −100% = Ч/Б |
| Color | Vibrance | насыщает приглушённые цвета |
| Color | Temperature | ≈ ось b* Lab (синий ↔ жёлтый) |
| Color | Tint | ≈ ось a* Lab (зелёный ↔ маджента) |
| Color | Hue | ±100% = ±180° по HSB-кругу |

- Общие контролы:
  - слайдер −100…+100%, дефолт 0;
  - Masking menu;
  - Invert mask (инвертирует и глобальную selection);
  - Hide effect (before/after);
  - Cancel, Confirm.
- В одной сессии можно менять несколько параметров, маска общая.
- Помнит последнюю коррекцию.

## Quick masks (общие для Adjustments и Filters)
1. **No Mask** (уважает глобальное выделение).
2. **Focus**: радиальная мягкая. Центр, inner ring (100%), outer ring (0%). Кольца вместе = жёсткий край.
3. **Tilt-shift**: линейная полоса. Центр (он же центр поворота), inner/outer edges. Поворот drag'ом между краями, snap 45°.
4. **Highlights**, 5. **Midtones**, 6. **Shadows**: тоновые диапазоны.
7. **Saturation**: сила ∝ насыщенности пикселя.
- Все инвертируемы и комбинируются с выделением.

## Tonal Curve (Curves)
- Каналы:
  - γ (RGB composite, открывается на нём);
  - R, G, B;
  - **A (alpha)**: подчищает размытые края слоёв и выделений.
- Узлы: тап = добавить, drag = двигать, drag на соседа = удалить. Все узлы убрать = линейный сброс.
- Hide preview, Cancel, Confirm.
- Примеры из доки:
  - инвертировать только γ = «gamma negative» (hue сохраняются);
  - инвертировать R, G, B = настоящий негатив.
