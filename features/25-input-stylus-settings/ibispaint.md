# ibisPaint: настройки, стилус, ввод

Источник: ibispaint.com/lecture №81 (Settings window), 151, 167, 197, 198, 199.

## Gesture
- Undo 2 пальца, Redo 3 пальца.
- **Quick Eyedropper** + своя задержка (слайдер).
- View Rotation (вкл/выкл).

## User Interface
- Reference Window.
- Window Color (тема).
- **Interpolation on Zoom In** + дефолт Display When Zoomed.
- Suggest Processing after Import (предложить Extract Line Drawing или Background Removal после импорта).
- Tool Select Position (Left / Right / Popup), колонки 1–3, подписи.
- Show Message on Undo.
- Sound.
- Layer Row Height (+ floating).
- Drag Left Side to Reorder Layers.
- Layer Thumbnail Whole / Only Contents.
- Background Color рабочей области.
- Keyboard Layout ANSI/JIS.
- Show Keyboard Shortcuts. **Custom keyboard shortcuts**.
- Disable Contents Layer Selection with Eyedropper.
- Invert Mouse Wheel.
- Pan with Trackpad Scroll.

## Pressure / Touch Offset
- Use Pressure Sensitivity.
- **Pressure Adjustment curve** (узлы: тап = добавить, drag за пределы = удалить).
- Weak Sensitivity.
- **Touch Offset** (сдвиг точки рисования стрелками), Mouse Offset на ПК.

## Cursor
- Brush Tool Cursor: None / Thickness Mark / **Brush Pattern**.
- Other Tool Cursor: None / Tool Icon.
- **Crosshair** у кончика пера (hover).
- Mouse cursor on canvas.
- Change Cursor by situation.

## Stylus
- Список поддерживаемых. Stylus Selection (Bluetooth-стилусы), Stylus Settings.
- **Palm Rejection**:
  - None;
  - **Hover** (пока перо над экраном, палец игнорируется);
  - **Canvas** (палец не рисует, но управляет UI);
  - **Driver** (только перо).
- **Double Tap / Squeeze** (Apple Pencil) или Button 1/2: назначаемые функции.
- **Barrel Roll** (вращение пера → угол кисти).
- Vibration Intensity (Lenovo Tab Pen Pro).

## For Professionals
- Save Bucket / Stabilizer / Shape tool / Selection / Filter / Adjustment layer settings между сессиями.
- Set Added Layer as Current.
- **Brush Thickness Depends on Canvas** (масштаб толщины с размером холста).
- Texture Memory Size (auto/ручной).
- **Brush Stroke Prediction** (предсказание для снижения задержки).
- **Touch History Completion** (coalesced touches, детальные события).

## Reset / Other
- Show tutorials again.
- Reset basic/custom brushes, palettes, filters, adjustment params, stylus.
- Uninstall fonts.
- Remove All References.
- Delete Brush Pattern cache.
- **Backup Settings (.ipcfg)**.
