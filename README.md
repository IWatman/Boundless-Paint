# Painter

Растровый редактор для рисования на Android-планшетах. Функционал объединяет возможности Infinite Painter и ibisPaint, интерфейс построен по схеме Infinite Painter. Реализация своя, с нуля, по правилам clean-room ([00-clean-room/PROCESS.md](00-clean-room/PROCESS.md)).

Приложение полностью бесплатное: никаких подписок, рекламы, водяных знаков и платных функций.

## Возможности

**Уже в приложении**
- Холсты: размеры экрана и печатные пресеты, галерея проектов (переименование, копия, удаление)
- Кисть и ластик: давление пера, стабилизатор, предсказание точек, отбрасывание случайных касаний пера
- Слои: добавление, копия, слияние, порядок, видимость, прозрачность, режимы наложения, клиппинг, alpha lock
- Цвет: колесо HSB, слайдеры, hex, палитра, пипетка (долгое нажатие)
- Undo и redo кнопками и жестами (тап двумя и тремя пальцами), навигация двумя пальцами
- Автосохранение через 2 секунды после изменения, экспорт PNG
- Обновление из приложения: проверка релизов на GitHub, скачивание и установка

**Готово в ядре, интерфейс в работе (M2)**
- Движок кисти: bitmap-головы, динамика от давления, скорости и наклона, jitter, тейперы, профили, калибровка пера
- Все 33 режима наложения, группы, маски слоёв и групп, 13 корректирующих слоёв (кривые, уровни, градиентная карта и другие)
- Выделения (лассо, прямоугольник, эллипс, волшебная палочка), трансформация (обычная, перспектива, warp), заливка, градиенты
- Гайды (линейка, эллипс, путь, штриховка), симметрия, перспективные сетки, распознавание фигур

Полный план: [spec/ROADMAP.md](spec/ROADMAP.md), текущая веха: [spec/PLAN-M2.md](spec/PLAN-M2.md), известные проблемы: [spec/STATUS.md](spec/STATUS.md).

## Установка

1. Скачайте `painter-X.Y.Z.apk` из [последнего релиза](https://github.com/IWatman/Painter/releases).
2. Откройте файл на устройстве и разрешите установку из этого источника. Нужен Android 10 или новее и поддержка OpenGL ES 3.
3. Дальнейшие обновления: кнопка «Обновления» на главном экране приложения.

> Версия 0.1.0 подписана другим ключом. Если она установлена, удалите её один раз и поставьте свежий релиз.

## Сборка из исходников

Нужны Windows, JDK 21 и Android SDK (platform 34). Все остальные инструменты (Gradle, эмулятор, Python-окружение) лежат локально в папке проекта, в `.tools/` и `.venv/`.

```powershell
. .\tools\env.ps1                                   # переменные окружения сессии
.\gradlew.bat :core:test                            # JVM-тесты ядра
.\gradlew.bat :app:assembleDebug                    # отладочный APK
.\gradlew.bat :app:connectedDebugAndroidTest        # тесты GPU на устройстве или эмуляторе
.\.venv\Scripts\python tools\gen_assets.py --check  # проверка процедурных ассетов кистей
```

Релиз подписанного APK с публикацией на GitHub выполняет одна команда: `.\tools\release.ps1 -Version 0.2.0 -Notes notes.md -Prerelease`. Для неё нужен ключ подписи в `.tools/signing/`, в репозиторий он не попадает.

## Устройство проекта

| Модуль | Что внутри |
|---|---|
| `core/` | Чистый Kotlin, без Android. Модель документа, тайлы 256² в half float, история, движок кисти, режимы наложения, коррекции, выделения, трансформации, заливки, гайды, формат проекта. Покрыт JVM-тестами |
| `app/` | Android-приложение: холст на OpenGL ES 3 (композит слоёв, маски, коррекции), обработка ввода и жестов, интерфейс на Jetpack Compose, обновления |
| `tools/` | Окружение, QA-хелпер для эмулятора, генератор ассетов кистей, скрипт релиза |
| `features/` | Функционал Infinite Painter и ibisPaint по 27 областям, описанный своими словами |
| `spec/` | Спецификации: каркас интерфейса, карта функций, решения, движок кисти, форматы, спеки инструментов по вехам |

Главные решения:
- **Растр:** штампы кисти и растровые операции считаются на CPU в `core` параллельно по тайлам, GPU отвечает за композит и превью. Отдельный тест проверяет, что композит на GPU совпадает с эталоном на CPU.
- **Формат проекта:** папка с `manifest.json` и тайлами в LZ4, экспорт в `.pnt` (ZIP).
- **Ассеты:** все головы кистей и текстуры генерируются кодом ([tools/gen_assets.py](tools/gen_assets.py)), сторонних изображений нет.

## Clean-room

Проект воспроизводит функционал существующих приложений, но не их код и ресурсы. Описания функций собраны из публичных источников ([00-clean-room/SOURCES.md](00-clean-room/SOURCES.md)) и пересказаны своими словами. Имена, параметры, алгоритмы и ассеты свои. Декомпиляция и копирование запрещены.
